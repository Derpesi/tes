# Standar Koding
- Ubah sekecil mungkin sesuai kebutuhan; hindari abstraksi spekulatif.
- Setiap fitur/perbaikan disertai tes; tes ditulis sebelum atau bersama kode.
- Fungsi kecil, nama jelas, tanpa kode mati.
- Format dan lint otomatis dipasang setelah stack dipilih; ikuti `.editorconfig`.
- Keputusan arsitektur penting dicatat sebagai ADR di `docs/architecture/`.
