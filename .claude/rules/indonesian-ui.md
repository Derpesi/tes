# Aturan UI Bahasa Indonesia
- Seluruh teks UI, pesan validasi, pesan error API, email, dan laporan berbahasa Indonesia.
- Format tanggal `dd MMMM yyyy` (locale id-ID), zona waktu Asia/Jakarta ditampilkan jelas, mata uang `Rp 1.234.567`.
- Mobile-first: dapat dipakai pada lebar 360 px; target sentuh memadai; aksesibilitas dasar (kontras, label, fokus).
- Warna: navy, putih, gold sebagai token tema; nilai final menunggu pemilik. Jangan membuat logo pengganti.
