# Alur Git
- Jangan push langsung ke `main`; kerja di branch fitur dan lewat PR.
- Commit kecil, atomik, dengan pesan jelas dalam bahasa Indonesia (imperatif, mis. "Tambah validasi input").
- Jangan force-push, jangan menulis ulang riwayat branch orang lain.
- Jangan skip hook atau menonaktifkan tes demi lolos CI.
- PR hanya dibuat atas permintaan pemilik proyek.
